### Valmera FCPXML Handoff Exercise

Valmera Editorial prepared a short practice exercise for checking a revised picture cut in Final Cut Pro. The download includes two FCPXML 1.10 sequences, a shared silent source video with a visible frame counter, and a separate reference MP4. Shortening one middle shot moves the start of the last shot from 00:08 to 00:06.

The exercise explains how to place or relink the source file and check the result in a practice library. The XMLs passed Apple's structure validation. Check import and relink in your own version of Final Cut Pro.
